# User Journey

Projeto: DSFR CornerLab

Versão: 1.0

---

# Objetivo

Definir toda a experiência do usuário dentro do CornerLab.

O sistema deverá ser intuitivo, rápido e orientado à tomada de decisão baseada em dados.

---

# Filosofia

O usuário nunca deverá ficar perdido.

Em qualquer tela ele deverá saber:

• Onde está
• O que aconteceu
• O que mudou
• O próximo passo

# Objetivo Final

Ao entrar no CornerLab

O usuário deverá conseguir

Em menos de 5 minutos

Responder

• O que mudou?

• Minhas estratégias continuam boas?

• Surgiu alguma oportunidade?

• Alguma estratégia perdeu eficiência?

✅ Fluxo intuitivo.

✅ Dashboard personalizado.

✅ Histórico completo.
