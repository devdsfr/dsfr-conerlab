# Design System

Projeto: DSFR CornerLab

Versão: 1.0

---

# Objetivo

Definir todos os padrões visuais da plataforma.

Todo componente deverá seguir este documento.

Nenhuma tela poderá criar componentes próprios sem passar pelo Design System.

---

# Filosofia

Poucos componentes.

Alta consistência.

Interface limpa.

Informação antes de decoração.

Priorizar leitura rápida.
