# Posicionamento

O CornerLab NÃO é um site de estatísticas.

O CornerLab NÃO é um site de apostas.

O CornerLab é uma plataforma de Inteligência Estatística para Futebol.

Seu objetivo é transformar dados históricos em inteligência quantitativa para análise de estratégias.

# Filosofia

O usuário não paga para ver estatísticas.

O usuário paga para economizar horas de análise, descobrir padrões, validar estratégias e tomar decisões fundamentadas em dados.

O valor do CornerLab está na inteligência produzida pela plataforma, não apenas nos dados apresentados.
